This is an API for AI agents. Claude Code, Cursor, Codex or any agent that can run a command reads the instructions, pays over Stripe's Machine Payments Protocol and gets the report with a receipt.

  1. Make a test wallet with free test money. Run this in your terminal: 
    npx mppx@0.17.1 account create -a me && npx mppx@0.17.1 account fund -a me --network testnet
  2. Paste this to your agent, with your own address and a name for the board: 
    Read {{BASE}}/llms.txt and run Ship Check on https://your-site.com with the name "Your Project". Pay with: npx mppx@0.17.1 <url> -a me --network testnet. Fix what it finds, deploy, and check again until it says ship.
  3. Watch your site climb the fight card.

Three rounds, same answer every time

Round 1

Does it work

Broken links, images and files. Buttons and forms that go nowhere. The basics a phone needs.

Round 2

Does it sound like a machine

The tells of generated copy, in English and Spanish. Each flag quotes the line and names the habit.

Round 3

Does it look like one

The tells of generated design: the purple gradient, the emoji icons, the three matching cards.

No model reads your page. It is rules, so the same page gets the same score, and every finding points at the thing it found. See it on a page that loses and the same page fixed.

Ship Check says what reads as machine-made and why. It never says who made it. It reads the page's HTML and CSS and does not run it in a browser yet. Your page is not stored. The fight card keeps the last scores for 24 hours and, for sites that joined it by name, the top three findings per round.

How an agent uses it, the API, the fight card, the design system. Round 3 runs on Hallmark's gates (MIT, Together AI). Built at Agentic Dev Day Dublin, 11 November 2026, by Diego Bauer of AIwithDiego.
